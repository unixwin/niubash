# Privacy Policy / 隐私政策

**Effective date: September 13, 2026**

Niubash is a Windows-native command-line shell. This policy applies to the Niubash shell and its bundled components (including WinuxCmd and the oh-my-niu plugin distribution).

## What we collect

**Nothing.** Niubash does not collect, transmit, or store any personal information. There is no telemetry, no analytics, no crash reporting, and no account system.

## What stays on your device

- Shell configuration (for example `~/.niubashrc`) and user data are stored locally on your device and never leave it.
- Plugin and package installation (WPM) makes network requests only when you explicitly ask it to install or update a package. These requests do not include personal information.

## Third parties

Niubash does not share any personal information with third parties, because it does not collect any.

## Changes

If a future version of Niubash ever changes how it handles information, this policy will be updated and its effective date revised before that version is released through the Microsoft Store.
