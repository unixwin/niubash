# Payload licenses

License texts and provenance for everything the Windows release archives
bundle besides `niu.exe` itself. `package-release.ps1` stages this directory
into the archive as `licenses\` (one subdirectory per component), so a user
who receives the binary also receives its license obligations.

Layout contract:

- One subdirectory per component: `gawk/`, `dll-closure/` (the DLL set that
  ships inside the gawk payload), `niugit/`, `ripgrep/`, `fd/`, `winuxcmd/`,
  `niubash/`.
- Each carries a `LICENSE` holding the canonical license text (for
  dual-licensed components, both texts with the disjunction stated in the
  header; for `dll-closure/`, `LICENSE` is an index into the per-license
  `LICENSE-*.txt` files beside it).
- Each carries a `PROVENANCE.md`: upstream project, exact version, where the
  binary came from, and the Corresponding Source pointer. Versions and
  SHA-256 pins are copies of `scripts/release/preinstall.json` /
  `scripts/release/winuxcmd-pin.json` -- those manifests remain the source of
  truth; if a pin is bumped, update the matching `PROVENANCE.md` in the same
  change.

Facts recorded here are evidence-backed (preinstall.json pins, wpm-source
index entries, wpm-artifacts release notes, niu-git build pins). Where a fact
could not be established from in-repo or upstream evidence, PROVENANCE.md
says so explicitly instead of guessing.

Repo-root `NOTICE` is the short human-facing attribution table derived from
the same manifests; `THIRD-PARTY-NOTICES.md` (generated by
`scripts/gen-third-party-notices.mjs` from Cargo.lock) covers niubash's own
Rust dependency tree.
